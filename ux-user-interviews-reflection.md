# How to Conduct User Interviews & Usability Testing

## Research & Learn

**What are best practices for conducting user interviews?**
UX designers should ask clear and open questions and let users share their thoughts. They should also listen carefully and avoid leading the user towards a specific answer.

**How do you run an effective usability test without influencing the user?**
Give the user a task and let them complete it on their own. Avoid giving them the answer or telling them what to click.

**What types of questions should UX designers ask during interviews?**
They should ask open questions about the user's experience, such as what they found easy, difficult, or confusing.

**How can recording and note-taking improve research accuracy?**
Recording and notes help designers remember what users said and did. They can also review the session later to find important details.

**What are common mistakes to avoid when conducting user research?**
Designers should avoid leading questions, interrupting users, making assumptions, and helping users too much during testing.

## Reflection

**If a user struggles with a feature during testing, how do you know if it's a UX problem or a learning curve issue?**
I would test the feature with more users. If several users struggle with the same thing, it could be a UX problem. If only one user struggles, they may just need more time to learn it.

**How can UX designers ensure they don't influence user responses during an interview?**
They should ask neutral questions and avoid suggesting an answer. They should also let users explain their thoughts in their own words.

**What's the best way to document usability testing results?**
I would record the main problems, user feedback, and any patterns I noticed. I would then organise the findings so they can be easily used when making design improvements.
