# Interpreting User Feedback & Usability Testing Insights

## Research & Learn

**What are common methods for analysing usability test results?**
Designers can look at user feedback, task completion, errors, and common problems. They can also look for patterns that happen with multiple users.

**How can UX designers avoid bias when interpreting feedback?**
They should focus on the feedback and evidence instead of their personal opinions. It also helps to compare feedback from different users.

**What's the difference between actionable insights and subjective opinions?**
An actionable insight shows a clear problem that can be improved. A subjective opinion is based on what one person likes or dislikes.

**How do you prioritize user feedback when users have different requests?**
I would look at how often the problem occurs and how much it affects users. I would also consider how important and realistic the change is.

## Reflection

**If one user complains about a feature but others like it, how should UX handle it?**
I would not immediately remove or change the feature. I would look into the problem further and see if other users have the same issue.

**How can patterns in feedback help identify real UX issues?**
If several users mention the same problem, it is more likely to be a real UX issue. This helps designers focus on problems that affect more users.

**What are the risks of making changes based on limited or unverified feedback?**
The change might solve a problem that only affects one person and could make the experience worse for other users. It is better to collect more feedback before making a big change.
